## 🏋️ Featured Project — FitLog

**A dark-themed workout library built with Next.js 16, TypeScript, Context API, and Tailwind CSS.**

🔗 **[Live Demo](https://assignment-6-one-phi.vercel.app/)** · 💻 **[Source Code](https://github.com/Asaduzzaman8088/assignment-6)**

**Highlights:**
- 📚 Browse 12+ workouts from a live REST API
- 🎯 Dynamic detail pages with specs, instructions, and ratings
- 📅 Add to Today's Plan (max 5 lifts) with live metrics
- 💾 Save workouts for later with localStorage persistence
- 🔀 Sort by duration, calories, or rating
- 📱 Fully responsive with custom 404 page
- 🎨 Custom brand color (#C2F800) with Oswald + Inter typography
